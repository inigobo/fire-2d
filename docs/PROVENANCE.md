# Source provenance and attribution

This project intends to implement a fire renderer from published fluid algorithms and documented graphics techniques. AI assistance can help explain the math, propose designs, and write original code. It does not change the provenance of copied source.

## Working rule

- Read papers, articles, demos, and repositories to understand equations, data flow, and visual behaviour.
- Write implementation code for this project independently. Do not paste source, shaders, distinctive functions, or generated close paraphrases from referenced repositories into this codebase.
- Acknowledging a source is good practice, but attribution alone is not permission to copy code. Check its license before reuse.
- If we intentionally incorporate third-party code later, record the files, source revision, license, modifications, and preserved notices here. Describe the project as an adaptation where appropriate.
- Keep haxiomic's GPL-3.0 source and repositories without an identified license as study references only under the current MIT plan.
- Avoid claims such as “first fluid solver” or “from scratch” for components that are adapted from another implementation. Describe our contributions precisely in the README and portfolio case study.
